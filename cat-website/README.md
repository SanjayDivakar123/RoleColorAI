# 🐱 Purrfect Cats Website

A beautiful, responsive cat website featuring adorable cat photos, breed information, fun facts, and interactive elements!

## ✨ Features

- **Responsive Design**: Works perfectly on desktop, tablet, and mobile devices
- **Interactive Gallery**: Hover effects and beautiful cat photos from Unsplash
- **Cat Breed Information**: Learn about popular cat breeds with ratings
- **Fun Facts Cards**: Click to flip cards and discover amazing cat facts
- **Contact Form**: Send messages with cat-themed validation
- **Smooth Animations**: Scroll animations, floating cats, and parallax effects
- **Mobile Navigation**: Hamburger menu for mobile devices
- **Easter Eggs**: Click the logo for random cat facts!

## 🎨 Design Highlights

- Modern gradient backgrounds
- Smooth hover animations
- Card-based layout
- Cat emoji integration
- Beautiful typography with Poppins font
- Responsive grid layouts

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Enjoy exploring the purrfect world of cats!

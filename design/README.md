## 🎨 Design Philosophy

RoleColorAI follows the RoleColorFinder design language with a focus on:
- **Clean & Geometric**: Modern, structured layouts
- **Friendly & Approachable**: Warm, inviting user experience
- **Color-Driven**: Strategic use of the four role colors
- **Professional**: Suitable for HR and recruiting contexts

## 🚀 Quick Start

1. Review the [color palette](brand/colors.md) for proper color usage
2. Check [typography guidelines](brand/typography.md) for font specifications
3. Explore UI components for consistent design patterns

## 📋 Brand Guidelines Summary

- **Primary Colors**: Red (#EE2B2B), Yellow (#FFDD33), Blue (#2B8CEE), Green (#27BD73)
- **Neutral Colors**: Steel Black (#242E42), Pure Black (#000000)
- **Typography**: Poppins font family (ExtraLight to Black weights)
- **Logo Order**: "Role" (Red) → "Color" (Yellow) → "AI" (following brand pattern)

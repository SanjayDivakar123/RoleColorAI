# RoleColorAI Logo Guidelines

## 🎨 Logo Concept

The RoleColorAI logo follows the established RoleColorFinder brand pattern, adapting it for the AI-powered resume enhancement platform.

### Logo Structure
Following the RoleColorFinder pattern:
- **"Role"** - Red (#EE2B2B) - Drive & Passion
- **"Color"** - Yellow (#FFDD33) - Optimism & Energy  
- **"AI"** - Blue (#2B8CEE) - Logic & Strategy

The period (.) uses Blue (#2B8CEE) to maintain the brand consistency while emphasizing the technological/logical aspect of AI.

## 📏 Logo Specifications

### Primary Logo
- **Font**: Poppins Bold (700 weight)
- **Letter Spacing**: -0.02em for tighter, more impactful appearance
- **Alignment**: Left-aligned, single line preferred
- **Minimum Size**: 120px width for digital, 1 inch for print

### Color Variations

#### Full Color (Primary)
```
Role (Red #EE2B2B) Color (Yellow #FFDD33) AI. (Blue #2B8CEE)
```

#### Monochrome Dark
```
RoleColorAI. (Pure Black #000000)
```

#### Monochrome Light
```
RoleColorAI. (White #FFFFFF)
```

#### Single Color Variations
- **Red Version**: All text in Red (#EE2B2B)
- **Blue Version**: All text in Blue (#2B8CEE)
- **Steel Black Version**: All text in Steel Black (#242E42)

## 🔄 Logo Usage

### Preferred Usage
1. **Full Color**: Primary usage across all digital platforms
2. **Monochrome Dark**: When color printing is not available
3. **Monochrome Light**: On dark backgrounds or overlays

### Clear Space
- Minimum clear space: Height of the letter "R" on all sides
- No other elements should appear within this clear space
- Maintain proportional spacing when scaling

### Backgrounds
- **Light Backgrounds**: Use full color or monochrome dark
- **Dark Backgrounds**: Use monochrome light or full color
- **Colored Backgrounds**: Ensure sufficient contrast (minimum 4.5:1 ratio)
- **Recommended Background**: Soft off-white (#F8F9FA) or light gray

## ❌ Logo Don'ts

### Never:
- Change the color sequence (Role must be Red, Color must be Yellow, AI must be Blue)
- Separate the words or rearrange them
- Add effects, shadows, or outlines
- Stretch or distort the proportions
- Use on backgrounds with insufficient contrast
- Place other elements too close (violating clear space)
- Use outdated or low-resolution versions

### Favicon
- Use simplified "RCA" monogram in brand colors
- Ensure visibility at 16x16px minimum
- Provide multiple sizes: 16x16, 32x32, 48x48, 64x64

## 📄 File Formats

### Required Formats
- **SVG**: Vector format for web and scalable applications
- **PNG**: High-resolution (300 DPI) with transparent background
- **JPG**: High-resolution (300 DPI) on white background
- **PDF**: Vector format for print applications

### File Naming Convention
```
rolecolorai-logo-[variation]-[size].[format]
```

Examples:
- `rolecolorai-logo-full-color.svg`
- `rolecolorai-logo-monochrome-dark.png`
- `rolecolorai-logo-horizontal-1200px.png`

## 🎯 Brand Consistency

### Relationship to RoleColorFinder
- Maintains visual connection to parent brand
- Uses identical color palette and typography
- Follows same geometric, clean design principles
- Clearly identifies as part of the RoleColor ecosystem

### AI Emphasis
- Blue color for "AI" emphasizes logic and strategy
- Maintains professional, trustworthy appearance
- Suggests technological sophistication
- Appeals to HR and recruiting professionals

## 📋 Logo Checklist

Before using the logo, ensure:
- [ ] Correct color sequence maintained
- [ ] Sufficient clear space provided
- [ ] Appropriate contrast with background
- [ ] Proper file format for intended use
- [ ] Minimum size requirements met
- [ ] No unauthorized modifications made
